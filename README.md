# 1. Project Name
E-Commerce Web Application
# 2. Project short introduction

This project provides a complete online shopping platform where users can browse and manage products through a user-friendly interface. It also provides secure authentication, email verification, password recovery, and role-based access for users and administrators, making the shopping and management process more organized and secure.

# 3. Main Features
User Registration and Login
JWT-based Authentication
Email Verification
Secure Password Hashing using bcrypt
Forgot Password functionality
OTP-based Password Reset
Password Change functionality
User Logout
Role-Based Authorization
Admin Dashboard
User Management
Product Management
Product CRUD Operations
Image Upload using Cloudinary
Protected API Routes
MongoDB Database Integration
Responsive User Interface
Secure REST APIs
Form Validation and Error Handling
